rule exists to catch. This is a script fix in `scripts/check-claims.mjs`
(a file this batch owns), not an edit to `tax.ar.json`; no request to S1 is
needed. `s2.*`, `seo.*` and `s6.*` do not exist yet at the time of this
review.
